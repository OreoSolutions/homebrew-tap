# OreoSolutions Homebrew tap

```bash
brew install --cask oreosolutions/tap/oreokey
```

Cập nhật: OreoKey tự cập nhật qua Sparkle; hoặc `brew upgrade --cask oreokey`.

Gỡ: `brew uninstall --cask oreokey` (thêm `--zap` để xóa cả cài đặt).

Cask này được `scripts/release.sh` của [OreoKey](https://github.com/OreoSolutions/oreokey) cập nhật tự động mỗi lần phát hành.
